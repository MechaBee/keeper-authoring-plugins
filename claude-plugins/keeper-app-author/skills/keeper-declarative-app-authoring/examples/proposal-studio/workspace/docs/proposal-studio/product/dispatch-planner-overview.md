# Larkspur Dispatch: overview

Dispatch plans routes for multi-drop delivery fleets and runs the day once vans are out.

## Planning

- Builds routes overnight from the order file, respecting delivery windows, vehicle capacity,
  driver hours and depot loading slots.
- Planners can drag stops between routes; Dispatch shows the effect on time and distance.

## On the day

- A driver app with turn-by-turn navigation, proof of delivery (signature, photo) and exceptions.
- A live map for the control room, with estimated arrival times that update as vans move.
- Customers can receive an arrival window by SMS on the morning of delivery.

## Integrations

Order import from most WMS systems by file or API. See the integrations catalogue.
