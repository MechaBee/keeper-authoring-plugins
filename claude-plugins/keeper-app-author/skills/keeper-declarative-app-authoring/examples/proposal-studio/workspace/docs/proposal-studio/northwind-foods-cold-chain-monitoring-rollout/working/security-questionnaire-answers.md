# Security questionnaire answers: Northwind Foods

## 1. Do you hold ISO 27001 certification?

Yes. Larkspur has held ISO/IEC 27001 since 2019; the current certificate is to the 2022 standard.

## 2. Where is our data hosted?

In AWS London (eu-west-2), with backups in AWS Ireland (eu-west-1).

## 3. Do you support single sign-on?

Yes, with Microsoft Entra ID, Google Workspace or any SAML 2.0 provider.

## 4. How long do you keep temperature records?

Seven years by default.
