# Ask questions about an issue

Use this when you cannot design or revise without answers from people. Your
questions are posted as one comment on the issue, and the issue waits for a
reply outside the Agent queue. Any person's comment puts it back.

## Before you ask

Read the issue, the whole `conversation` and the issue's `documents`, and the
code if you are working in it. Never ask something the issue, the conversation,
the documents or the code already answers.

## The questions (`questions`)

`questions.body`: Markdown, at most five questions, as a numbered list. For each:

- the question itself, answerable in a sentence or a choice;
- why it matters for the design, in one line;
- your default, if you have one ("If nobody objects, I'll …").

Start with one line on what you understood the issue to be, so people can
correct a misunderstanding first. The issue shows the comment as written by
Agent (on behalf of the person who ran you), under a **Questions** heading.

## After saving

Tell the person the issue's reference and that it now waits on answers. The
issue's author and assignee are notified of the new comment.
