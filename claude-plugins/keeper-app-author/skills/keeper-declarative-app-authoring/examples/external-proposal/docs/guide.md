# Proposal Tracker

Ask your connected agent to draft a proposal, then select an opportunity through the task's input
options. The agent reads its scoped context and submits a draft for review. Select the opportunity
in the review view and accept its run to save the summary and link its document.

Uncommitted draft documents remain in the workspace after cancellation, rejection, or expiry.
External runs use the connected agent's model; Keeper does not launch or bill a managed AI worker.
