# Security

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[info@mechabee.com](mailto:info@mechabee.com). Include reproduction steps and the affected plugin
version when possible. Do not open a public issue for an unpatched vulnerability.

## Credentials

The plugin authenticates to MechaBee through OAuth. Never add access tokens, passwords, MFA codes,
private keys, or local environment files to this repository.
